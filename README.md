# reMarket — Classifieds Web Application

A responsive front-end marketplace project built with HTML, CSS and JavaScript.

## Files
- `index.html` — login screen, marketplace layout, listing and detail modals
- `style.css` — premium responsive Midnight Purple design (near-black surfaces, violet accents and lavender highlights)
- `script.js` — sample listings, search, category filtering, sorting, favourites, product posting and WhatsApp contact

## Run
1. Extract this folder.
2. Open it in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Features
- Demo sign-in screen and guest access
- 12 sample listings with online product photos
- Search by name, category, location or description
- Category filters and price/date sorting
- Save/favourite items
- Product detail modal
- Post new product listings
- Seller contact via WhatsApp confirmation
- Responsive mobile layout
- Browser localStorage persistence for new listings and saved items

## Important demo limitations
- Sign-in is a front-end demonstration, not secure authentication.
- Listings and favourites are saved only in the current browser using localStorage.
- Sample listings and contact numbers are demo data. Do not rely on them for real transactions.
- Product photos are loaded from Unsplash over the internet, so an internet connection is needed to display them.
- For a production app, add a backend/database, secure authentication, moderation, image upload storage and server-side validation.
